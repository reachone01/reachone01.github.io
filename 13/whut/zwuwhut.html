以下重点整理了一些关于保研，特别是外保的资料。不管是不想保研，还是有本硕连读的机会（也有考核），为避免迷茫，大学的规划循着保研这条线走，也是很好的参照。（个人感觉武汉理工这个专业的师资一般。）

  1. 录取结果就是最好的安排！
  2. 沟通常识与礼仪：沟通是双向的，要有反馈。如微信沟通不要吝啬“收到”、“知悉”、“辛苦了”、“谢谢”等词汇，是基本沟通常识，也是基本礼仪。
  3. 床位选择：靠窗通风，远离卫浴与空调的上下铺就是最好的选择（能尽量远离灯的开关也最好，不然每天不论早晚都是你来开关灯）。
  4. 避免太多无效社交和加入太多社团，但维护与老师的关系很重要（关系到评优、保研、科研、竞赛机会、实习推荐）。
  5. 大一新生注意避坑：现在坑新生已经形成完整产业链，骗子会伪装成热心学长学姐，利用大家信息不足、怕脱离集体的焦虑设套。常见套路有制造刚需假象推校园卡宽带、卖劣质高价复习资料、招免费劳动力的空壳社团、收押金培训费的虚假兼职、贩卖焦虑诱导消费的成长类课程。应对核心就是别当场交钱，延后做决定多咨询核实信息，报社团前问清实际情况，养成主动查证的习惯，既能少踩校园坑，也能提前规避步入社会的陷阱。ref
  6. 大一很关键，通常都还没调整过来，一下直接放轻松了，没把心思放在学习上，只要稍注意时间管理和学习就可拉开GPA差距（见后面名词解释）或参加评优！
  7. 学习方法和学习导向都很重要，一定要清楚业界需求导向，专业匹配哪些职业？职业的社会价值或意义？职业的工作内容需要哪些理论和实践积累？让学习变得更有动力。从课程中挖掘出兴趣点，让学习变得不枯燥。
  8. 保研早规划、早成功（早开始，也早结束），可以优先选学校、专业、导师。保研冲五保六。看保研流程：本校推免资格 → 目标院校考核/预录取（各高校会开放保研夏令营，在大三下学期，看的是前五个学期的成绩。） → 系统填报 → 复试（大四上学期复试拿保研资格，看的是前六个学期的成绩）。 
    9. 本校推免资格需要考量基本资格与综合成绩排序：

基本门槛：大多数学校会先看学生是否符合推荐条件，常见要求包括：应届本科毕业生、遵纪守法、无违法违纪处分记录、无考试作弊或学术不端记录；已完成前三年或前四年培养计划要求；课程成绩达到一定范围。有的学校还会要求必修课无不及格、英语达到四级或六级标准。

综合成绩：核定人选时，核心通常是综合成绩排名。公开细则里很常见的做法是：学业成绩占大头，综合素质或考核成绩占小头。比如有的学校采用“学习成绩85%＋思想素养5%＋综合素质和能力测评10%”的结构；也有学校采用“学业成绩85%＋考核成绩15%”的百分制结构。学业成绩一般看前若干学期的主修课程、必修课程或专业课程的加权成绩、平均学分绩点。部分学校明确按首次成绩计算，补考、重修成绩不用于推免排序。所以推免看重的往往不是“最后补回来就行”，而是原始学习表现。

加分项目：科研、竞赛、论文、专利、社会服务、体育艺术等，通常不会单独决定能不能保研，但会影响综合成绩或作为特殊学术专长认定。有些学校要求专家审核小组对科研成果、学科竞赛等材料进行真实性、相关性和个人贡献审核，必要时还要公开答辩。
大学期间最稳的主线还是先把专业课和数学基础打牢，再用竞赛、科研项目、论文或实习去提升综合成绩中的非学业部分。

  17. 准大一必须学会的5个拿高绩点秘诀 ref
    18. 大一一定要提前了解到冲高绩点的捷径，大学里无论你是评奖评优还是保研留学就业，都是需要高绩点的，它是会伴随你一生的履历。这一期呢，我给大家揭开大学高绩点的真相，全是干货，点赞收藏加关注。我当年上学的时候，其实我本来是个学渣，我考上九八五吉林大学之后，大一上非常不适应，专业三十三个人，我考的是二十二名，几乎倒数，但是我后来悟透了大学的学习方法，大二第五，大三第一，一路逆袭保研。 

第一个技巧，我们要学会选老师。都听说过大学选课对不对？比如说电影赏析、大学生心理健康这类通识选修课，还有很多跟专业相关的要选的叫专业选修课。这种选课，记住，很多同学是凭兴趣去选，我告诉你，完全不对，你一定要优先选给分高、作业不难的老师。有的老师手很紧，每个学生最高给个八十分，有的老师不仅划考试重点，给学生打分也都是九十以上。你要是选了给分低的老师，就算是你比其他同学更努力，最后也是倒数。所以说，第一步，选对老师真的是可以让你事半功倍。 

第二个，一定要学会占水课的便宜。都听说过大学的水课吧，比如说马原、毛概、思修、形势与政策，这叫通识必修课，也就是我们常说的水课。既然是必修课，你就没得选，也没得逃。这种水课你真的要每节课死磕认真学、拼命去背吗？我告诉你不是的，我们这种水课每门课都是有平时分的，水课的平时分占比通常是非常高的，就算是你卷面只考五十分，说实话老师都能给你拉回来。教你一招：老师上课提问的时候，大部分同学其实都在下面玩手机或者做其他的事情，这个时候我们只需要耍一点小心机，主动举手帮老师缓解尴尬，不需要你的回答质量有多好，老师也会给你平时分打最高分。 

第三个，你想要拿高平时分还有个小妙招。平时分包含课后作业、出勤、课堂回答问题三类，但是大学课上这么多学生，老师根本记不住所有的名字，怎么打分？只要你上课多坐第一排和第二排，多刷脸，再加上你经常举手回答问题，出勤率高、主动回答问题的同学，平时分一定是满分。如果有课堂小组展示的作业，建议主动去做牵头负责的人，虽然负责工作会多一点，但是你的课后作业打分一定最高。在老师眼里，上课积极、作业积极的学生，最后阅卷的时候打分手一定很松，平时分也会给得更高。 

第四个是专业课，专业课难度确实比较大，平时分占比比较少，老师打分严，主要靠期末考试的分数，但也是有办法的。我们要早做打算，开学第一个月，咱们尽量做好三件事：第一个，联系上过这门课的直系学长学姐，向他们了解老师的出题风格，还可以买一份往届的上课笔记，对症下药；第二个，通过学长学姐、打印店渠道，提前拿到历年的期末真题。因为大学期末考试很多时候是换汤不换药的，甚至有些卷子会反复用原题，谁先拿到真题谁就更容易考高分；第三个，期末备考的时候，把平时上课的作业和PPT上面的例题全部做一遍，这都是老师精挑细选出来的题目，也一定是期末考试的重点。 

第五个，大学最后两节课是用来划重点的，所以期末前的最后两节课一定不能缺课，带好书和笔记本认真听，最好再录下来。高中咱们三年就考那几本书嘛，但是大学一学期要考十几门科目，你复习起来会非常吃力。技巧就是，大多数老师都会在期末前几节课划考试重点，一节课能梳理完一学期的考点。刚上大学大家都不懂，你听到就是赚到。
  18. 三类保研竞赛，帮大家提前规划加分路径：
    19. 第一个是全国大学生英语竞赛，每年2-3月报名、4-5月校内初赛，成绩在校内达一定比例就能拿国家级三等奖，各类院校学生都有机会，适配所有同学参与。 
第二个是数学建模竞赛，分国内国赛和国际美赛，能锻炼建模、逻辑分析和编程能力，优秀论文还能发表；需要组队，选靠谱队友很重要，适合对数学、编程感兴趣的学生。 
第三个是互联网+、挑战杯，属于国内高校A类顶尖竞赛，加分权重高，拿国家级最高奖项的话，部分顶尖院校能直接给保研资格；对项目、团队、导师资源要求高，建议加入校内往届获奖团队或跟资深导师筹备，别独自从零起步。 
最后建议结合专业、兴趣和资源提前规划，竞赛经历也能提升综合实力哦～
  19. 保研面试避坑指南 读了研才知道 为什么大家的保研面试过不了 ref
    20. 读了研才知道为什么大家的保研面试过不了。我亲身经历过保研，也调研了身边所有参加过保研的同学。越复盘越明白一个道理，很多人被刷根本不是因为不够优秀，而是从头到尾都没搞懂面试官到底要考什么。 今天我把保研面试最容易犯也最致命的五个坑，一次性给你们扒出来，这五个坑只要踩到一个，你的面试就悬了，踩两个基本就直接没戏了。 

第一个坑也是最常见的，把展示自己变成了背简历。不少同学一进面试的教室就一股脑的讲自己拿了什么奖，做了什么项目，发了什么论文，语速还特别快。老师听完后问一句，这个项目你主要负责了哪个部分？当场就卡住了。 其实老师要听的不是你的结果，而是你拿到结果的过程。在做项目的过程中用了什么方法，遇到了什么问题，发论文的时候审稿人提了什么意见？你又是怎么修改的？这些才是老师最在意的。给大家一个思路，就是每一段经历都准备一个三句话的故事：遇到了什么问题，你是怎么想的，最后是怎么解决的？ 

第二个坑，遇到不会的问题就去硬编，或者直接说不知道，这是最容易扣分的地方。其实老师都清楚本科生能会多少东西，他们不想看你什么都会，想看的是你在不会的时候怎么应对。在碰到不会的问题的时候，正确的做法应该是先承认不会，然后补充你的理解。比如“这个概念我没有系统学过，但我了解过相关的概念，我的理解是什么什么，您看这个方向对吗？”这样的话，坦诚并且有逻辑反而加分。 

第三个坑，对导师的了解只停留在名字和方向。保研面试里最尴尬的就是老师问你“对我们组做什么了解吗？”你回答“了解，做人工智能的”，然后老师再追问“具体呢？”然后你就不会回答。这也不是你不努力，而是努力错了方向。网上的方向大概率是三年前的，导师现在研究什么、最近发了什么文章、有什么新想法，这些才是你应该去了解的。建议大家面试前花半天时间去谷歌学术搜一下导师近两年的文章，不用全看懂，捋捋标题、摘要、关键词，面试的时候随口提一下他最近的论文，老师就会瞬间觉得你是真的想来，直接好感度拉满。 

第四个坑，回答问题像挤牙膏，等着老师问。很多同学面试的时候，老师问一句话，他就只答一句话，答完就坐着等，问一点说一点，整体显得非常被动，根本展示不出来你自己，并且显得你非常没有积极性。比如老师问你做过什么项目，别只说“做过一个设计的项目”就停了，主动去补充这个项目用到了什么软件，当时碰到了什么问题，后来通过什么方式解决了，也不用追着老师问，就自然的对话就好。 

第五个坑，反问环节问错话。最后老师问你“有什么想问的？”，这其实是隐形考察项，不要问住宿条件怎么样、食堂好吃吗、毕业能找到什么样的工作。你还没有被录取，就先关心生活待遇，这样的问题只会让老师觉得你读研的动机不纯粹，不是来做学术的。建议问学术和成长相关的，比如“您觉得组里做的好的学生通常具备什么特质？”“如果我提前进组，您建议我补哪方面的基础？”这样既显得有上进心，又能拿到有用的信息。 

最后跟大家说一句，面试和笔试不一样，没有标准答案，老师坐在对面不是要考倒你，而是去筛选以后一起做课题的人。

名词

  1. GPA（Grade Point Average，平均学分绩点）是以学分加权计算的学业质量量化指标，核心功能是将课程成绩转化为标准化数值，用于综合评价学生的学习质量而非单纯数量。国内高校普遍采用4.0或5.0制，但2025年起北京大学等部分高校已宣布取消绩点制，转向等级制评价，以缓解“唯分数论”的内卷问题。

    2. GPA是学分加权后的平均绩点，与单纯算术平均分有本质区别：高学分课程对GPA的影响权重更大。例如，4学分的专业课成绩比2学分的选修课对GPA的拉动作用更显著。

    国内高校常见规则
4.0制换算标准（以多数高校为例）：
90-100分 → 4.0
85-89分 → 3.7
82-84分 → 3.3
78-81分 → 3.0
60分仅对应1.6-2.0绩点，远低于“及格即可”的误区。
5.0制：部分高校（如中国科学院大学）采用更细分的绩点区间，但逻辑相同。
主流计算公式：
GPA = Σ（单科绩点 × 课程学分） ÷ 总学分
（分子为所有课程的“学分绩点”之和，分母为纳入统计的总学分）。
示例：
3学分课程A（绩点4.0） + 4学分课程B+（绩点3.3） + 2学分课程C（绩点2.0）
GPA = (3×4.0 + 4×3.3 + 2×2.0) ÷ (3+4+2) = 3.29。

不计入GPA的课程类型：二级制（合格/不合格）课程、旁听课、退选课（W）、未完成课（INC）等，仅核算计入总学分的课程。
  2. 推免（推荐免试攻读研究生）是指普通高校按规定遴选优秀应届本科毕业生，直接免去全国硕士研究生入学统一考试初试环节，通过招生单位复试后录取为硕士或博士研究生的选拔方式。其本质是以本科阶段综合表现替代考研初试，但获得推免资格不等于最终录取，需通过目标院校的复试考核并在教育部系统中完成确认。
    3. 全称：普通高等学校推荐优秀应届本科毕业生免试攻读硕士学位研究生。
三大环节：  
  推荐：本校遴选具备免试资格的学生（需满足成绩、英语等硬性条件）；  
  免试：免去全国硕士研究生入学统一考试初试，但仍需参加招生单位组织的复试；  
  接收：招生单位通过复试考核后，在教育部系统中发放待录取通知。

关键流程与时间节点
9月22日9:00起：推免生登录教育部“推免服务系统”（https://yz.chsi.com.cn/tm）填报志愿，可同时提交3个平行志愿（48小时内不可修改）。  
9月23日起：招生单位发放复试通知，考生需在规定时间内确认是否参加。  
9月25日14:00起：系统开放待录取通知确认功能，考生仅能接受1个待录取通知，确认后不可更改志愿。  
重要补充：多数顶尖院校（如清北复交）会通过夏令营（6-8月）或预推免（9月系统开放前）提前选拔，建议主动关注目标院校官网通知。

基本门槛
学业成绩：专业排名通常需在前10%-30%以内（具体比例由本校政策决定），无挂科记录是硬性要求。  
英语水平：多数院校要求英语六级≥425分，部分顶尖高校或专业（如国际法、医学）隐性门槛达500-550分以上。  
其他要求：无违法违纪记录、身心健康、本科毕业前须取得学位证。

加分项与差异化竞争
科研成果：发表论文、专利、大创项目等可显著提升竞争力，尤其对直博生申请至关重要。  
学科竞赛：国家级奖项（如“挑战杯”、“数学建模”）在复试中具有关键加分作用。  
综合素质：学生工作、志愿服务等经历需与专业方向相关，避免“为加分而堆砌”。

必须纠正的认知偏差
推免资格≠录取成功：获得本校推免资格仅表示具备申请资格，最终需通过招生单位复试，且部分院校会复审最后一学年成绩。  
系统确认决定录取：即使通过复试，未在“推免服务系统”中确认待录取通知则录取无效，且确认后不可反悔。  
跨专业限制：医学、法学等专业通常要求本科专业严格对口，跨考需提前确认目标院校政策。

实操注意事项
夏令营优先策略：顶尖院校（如上海交大、人大）70%以上名额在夏令营阶段已确定，务必提前准备材料并积极投递。  
英语短板补救：若六级未达目标院校隐性门槛，可紧急备考雅思/托福（如案例中六级593分者10天考出雅思7.5）。  
材料真实性风险：提供虚假信息一经查实，将取消推免资格并记入诚信档案。

推免的核心逻辑是以本科全程积累替代短期应试，需从大一起注重学业成绩、科研实践与英语能力的系统性准备。若已进入大三，应重点跟进目标院校夏令营通知（通常3-6月发布），并针对性优化个人陈述与面试策略。最终录取结果以教育部“推免服务系统”操作为准，切勿轻信非官方渠道承诺。

  4. 大创项目（大学生创新创业训练计划）是教育部主导实施的国家级项目，以"兴趣驱动、自主实践、重在过程"为核心原则，面向本科生开展科研训练与创业实践的系统性培养计划。其本质是通过项目制管理，推动本科生早进实验室、早参与科研，强化创新思维与实践能力，而非单纯追求成果产出。
    5. 一、项目核心定义与定位
根本目标
深化高校创新创业教育改革，构建"了解→参与→主持→指导"的递进式培养模式，重点培养过程能力而非结果导向。  
作为中国国际大学生创新大赛（原"互联网+"大赛）等高水平赛事的核心项目来源，实现"以赛促创、以创育人"。

三级管理体系
国家级：由教育部直接管理，经费支持标准创新/创业训练项目≥2万元/项，创业实践项目≥10万元/项。  
省级：由省级教育部门统筹，经费标准通常略低于国家级（如部分省份要求≥1.5万元/项）。  
校级/院级：高校自主设立，经费由学校保障（校级项目普遍≥0.8万元/项）。

二、三类项目的核心区别
创新训练项目
定位：本科生科研参与的最主要途径，占项目总量的70%以上。  
关键要求：  
  个人或团队（≤5人）在导师指导下自主完成研究设计、实施及报告撰写。  
  强调科研基本功训练，需体现文献综述、实验设计、数据分析等完整流程。

创业训练项目
定位：模拟企业运营的商业实践训练，侧重经营管理能力培养。  
关键要求：  
  团队成员每人需承担具体角色，完成商业计划书、可行性研究、企业模拟运行等任务。  
  成果需包含可验证的商业逻辑（如市场调研数据、财务模型），而非单纯创意描述。

创业实践项目
定位：真实创业活动的孵化载体，要求成果具备市场转化潜力。  
关键要求：  
  必须配备双导师制（1名校内导师+1名企业导师），团队可含研究生。  
  需基于前期创新/创业训练项目成果，提出可落地的产品或服务方案，并开展实际运营。

三、关键实施规则
参与资格限制
学生：仅限全日制在读本科生，每位学生同期只能主持1个项目，参与总数≤2项；毕业年级学生须在离校前结题。  
团队：成员数创新/创业训练项目≤5人，创业实践项目可放宽至8人，鼓励跨学科组队。

过程管理重点
中期检查：需提交阶段性成果（如实验数据、调研报告），无实质性进展的项目将终止。  
结题标准：  
  创新训练项目：必须形成完整研究报告，鼓励发表论文、申请专利等。  
  创业类项目：需提供商业计划书、模拟运营记录或实际运营证明。

经费与成果转化
经费使用：仅限项目直接支出（资料费、实验耗材、调研差旅等），严禁用于生活开支。  
成果转化：  
  项目成果必须标注"获大学生创新训练计划项目资助"（含项目编号）。  
  优秀成果可直接推荐至创新创业大赛，部分高校允许兑换创新学分或推免加分。

四、学生参与价值与常见误区
真实价值点
科研能力奠基：90%以上的国家级项目要求选题源自教师科研课题，实现"早进实验室"。  
升学竞争优势：结题报告可作为推免复试材料，国家级项目优秀成果在部分高校推免中可获学术加分。

必须规避的误区
重申报轻过程：中期检查淘汰率普遍达10%-15%，仅提交计划书无法通过验收。  
成果过度包装：结题需提供原始实验记录、调研问卷等过程性证据，虚构数据将导致项目终止。  
忽视团队协作：成员分工需明确记录，实际参与度不足者不得列为成果完成人。

大创项目的核心价值在于通过规范化的科研/创业流程训练，培养系统性解决问题的能力。学生应聚焦过程投入而非功利性目标，优先选择与专业结合紧密、有真实问题背景的课题。若计划申报，需提前3-6个月联系导师确定选题，并严格遵循本校《大创项目管理办法》中的时间节点（通常每年4-6月集中申报）。最终成果质量远比项目级别重要，扎实的过程记录比论文专利更能体现培养实效。
